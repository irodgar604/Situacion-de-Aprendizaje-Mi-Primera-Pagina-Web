Computación y Robótica - 1º ESO

1. ¿Qué es la web?

Diferencias entre Internet y Web

Para entender el desarrollo de páginas web, lo primero que debemos saber es qué son, dónde se almacenan y cómo viajamos por ellas. Aunque a menudo usamos las palabras Internet y web como si fueran lo mismo, en realidad no lo son.

  • Internet es la infraestructura: es una gigantesca red global de ordenadores, cables submarinos, antenas y satélites conectados entre sí en todo el mundo.
  • La web es un servicio: es el sistema de páginas, imágenes, vídeos y documentos que consultamos a través de Internet.

Podemos imaginar que Internet es como la red de carreteras de un país. La web es uno de los tipos de vehículos que circula por ella (como los camiones de reparto). Pero también hay otros "vehículos" que usan Internet, pero no son la web, como las llamadas de WhatsApp, los juegos online o el correo electrónico.

¿De dónde viene la palabra web?

El nombre completo de la Web es World Wide Web (de ahí las famosas siglas www). Significa "Red de Alcance Mundial".

Se le llama "red" o "telaraña" porque las páginas no están ordenadas en fila como los libros de una biblioteca, sino que están conectadas entre sí mediante enlaces (hipervínculos). Al hacer clic en un enlace, saltas de un documento a otro que puede estar guardado en un ordenador en la otra punta del planeta.

Características de una página web

Por lo que acabamos de aprender, podemos deducir que una página web se trata realmente de un documento (o más bien, un conjunto de documentos) que se encuentran en Internet, a los que podemos acceder a través de la web.

Una página web tiene 3 características principales:

  1. Es digital: se almacena en ordenadores o servidores, y se transmite a través de señales eléctricas (es decir, no está almacenada físicamente o en papel).
  2. Es hipertextual: contiene enlaces (links) que te permiten navegar libremente de una información a otra.
  3. Es multimedia: no solo contiene texto, sino que combina imágenes, audios, vídeos, mapas, botones y otros elementos interactivos.

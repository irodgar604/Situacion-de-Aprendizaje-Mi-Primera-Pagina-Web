5. El código de las páginas web

Código web

Como ya sabemos, las páginas web son realmente un conjunto de archivos, imágenes o documentos que un servidor almacena, y cuando nos conectamos a él, nos los envía a nuestro ordenador.

Pero ¿Cómo hace nuestro ordenador para transformar todos esos archivos en una web con botones, imágenes, colores y todo lo que se nos ocurra? Esto es porque existe un código o lenguaje para escribir páginas web.

Lenguajes más importantes

Los lenguajes utilizados para el código de las páginas web son tres:

HTML

Define todo el contenido que hay en la página: títulos, párrafos, tablas, imágenes, botones... Es la estructura general de la página web.

CSS

Se encarga de darle estilo a la web, modificando los colores, tamaños, tipos de letra, márgenes, etc. Es el código que hace que la página se vea más bonita y con mejor apariencia.

JavaScript

Hace que la página responda cuando el usuario interactúa: animaciones, desplegables, cálculos. Permite que la web no esté siempre igual, sino que cambie según lo que haga el usuario.

Y lo mejor, es que el código de cualquier página web es público y podemos verlo. Tan solo hay que hacer Click derecho en cualquier sitio de la web y darle a Inspeccionar. Puedes investigar más sobre ello en el Ejercicio de Ampliación: Inspección de páginas web.

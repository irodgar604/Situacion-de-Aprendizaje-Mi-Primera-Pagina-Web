Ejercicios y Tareas

Introducción

Durante esta Situación de Aprendizaje se realizarán varios ejercicios y actividades antes de terminar con el producto final. En este apartado se encuentran todas estas actividades.

Estos ejercicios están preparados para ser llevados a cabo en el aula y ser entregados a través de la plataforma educativa que use cada centro, como Google Classroom o Moodle.

Se pueden distinguir tres tipos de actividades:

  • Lecturas: consisten en la lectura de una noticia o artículo relacionado con los contenidos de la Situación de Aprendizaje, para posteriormente responder a un cuestionario de comprensión lectora.
  • Google Sites: son ejercicios prácticos de realización y desarrollo de varios sitios web con una temática y requisitos concretos. Sirven para familiarizarse con todas las herramientas de Google Sites antes de realizar el producto final.
  • Ejercicio de ampliación: este ejercicio se propone para aquel alumnado que especialmente motivado o que quiera profundizar más en los contenidos de la Situación de Aprendizaje. No se propone como un ejercicio obligatorio.

Si eres docente, revisa la Guía didáctica para observar la relación completa de las tareas con los criterios de evaluación de la materia, así como la Línea Temporal para ver una recomendación de temporalización para estas actividades.

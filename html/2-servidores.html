2. Servidores

La arquitectura cliente-servidor

Cuando entras en cualquier página web, se activa un proceso de comunicación entre dos ordenadores que tienen funciones muy distintas: el Cliente y el Servidor.

  • El Cliente: es el dispositivo con el que nos conectamos a Internet, como nuestro ordenador, móvil o tablet. Es quien pide la información. Cuando escribes una dirección web y pulsas Enter, tu navegador envía una solicitud por Internet diciendo: "Quiero ver esta página".
  • El Servidor: es como un superordenador que funciona 24/7. Es un ordenador especial, conectado siempre a Internet, donde se guardan los archivos de la web (imágenes, textos, código). Recibe tu petición, busca los archivos y te los envía de vuelta. Funciona como si fuera la “cocina de un restaurante”.

¿Qué hace especial a un servidor?

  • Nunca se apaga: está funcionando las 24 horas del día, los 365 días del año, para que la web esté disponible siempre.
  • Atiende a miles de personas a la vez: puede responder a peticiones de muchos clientes simultáneamente, para que muchas personas puedan acceder a la web a la vez (aunque todo tiene un límite, por eso a veces se “satura”).
  • Guarda la información: aunque el tamaño de un servidor no es mucho más grande que el de un ordenador común, normalmente se almacenan muchísimos servidores interconectados en un mismo lugar, del tamaño de un instituto o una fábrica, de forma que están protegidos y refrigerados. Estos se llaman centros de datos o Data centers.
